# Legame - mod di coppia (Fabric 1.20.1)

## Come ottenere il .jar (senza installare nulla)
1. Crea un account su github.com e un nuovo repository (privato va bene).
2. Carica TUTTO il contenuto di questa cartella (compresa la cartella nascosta .github).
3. Vai nella tab "Actions" -> parte da solo "build" (2-4 minuti).
4. Apri l'esecuzione finita -> in fondo "Artifacts" -> scarica "legame-mod".
5. Dentro lo zip c'e' legame-1.0.0.jar.

## Installazione
- Fabric Loader per 1.20.1 + Fabric API 0.92.2 (mod obbligatoria).
- Metti legame-1.0.0.jar e Fabric API nella cartella mods.
- Va installata su server E su tutti i giocatori (o in singleplayer/LAN).

## Uso
/coppia richiedi <giocatore>, /coppia accetta, /coppia info, /coppia missioni, /coppia premi
Click destro sul partner: abbraccio / sneak = bacio / cibo = imbocchi
/coppia tradisci <giocatore>, /coppia uccidi, /coppia rompi
